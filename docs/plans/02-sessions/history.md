## Interfaces and bounds

`HistoryService` resolves `SessionTarget {run_id, session_key}` through the session store for **every** page, content, plan, navigation and watch operation. Resolve a source slot (`args | context | assignment | skill | plan | result`) against its stored owner/reference pair when supplied. Both must belong to the same registered run, MR and provider. A child must prove its ancestry. A caller supplies a target and opaque refs, never filesystem paths. HTTP and MCP convert wire types to use-case input. The app port uses app/domain types only.

| Required provider port | Result and ownership |
| --- | --- |
| `page(session: RegisteredSession, source: SourceSlot?, query: HistoryQuery, cancel: CancellationToken) → HistoryPage` | Query accepts cursor and older/newer direction, or an aroundId with optional signed locator, or default tail. Ascending native order. `HistoryPage {items,previousCursor,nextCursor,generation,availability,reset,retryAfterMs?}`. Exclusive cursors extend either end without duplicating the boundary entry. |
| `content(session, slot?, ref: ContentRef, cursor?, cancel) → ContentChunk` | Ref binds run, exact source/session/generation, native entry, ordered part/block and allowed content kind. `{text,nextCursor,complete,generation,availability,reset}`. Decode valid UTF-8. The opaque cursor tracks the byte boundary in the decoded stream. A chunk may end before the byte cap to preserve a scalar. |
| `navigation(session, query: Overview{maxGroups?} or Previews{cursor}, cancel) → NavigationPage` and `plan(session,cancel) → Plan` | Overview gives total confirmed user prompts, completion flag and bounded groups. Previews return ordinal, entryId, short text, timestamp, signed locator and continuations. Plan returns current ordered native steps/Markdown plus availability. |
| `watch(session, notify: HistoryHintSink) → WatchLease` | Share one observer per active source. Drop last lease to stop the watcher and cancel idle work. Hints carry session/generation. A gap requests a window reload. |
| `evidence(session, query: NativeEvidenceQuery, cancel) → VerifiedEvidence or Unavailable` | Typed variants for current native call, completed tool call and its structured acknowledgement, turn outcome/root, exact final response parts, exact submission observation, native spawn proof and reported settings. Bind session/turn/call/item/generation and verified position. Expose a streaming exact-body reader to report validation, in chunks of at most 64 KiB. REPORT owns the [separate full-document parse budget](../../specs/review-workflow.md#semantic-indexing-budget). A preview or partial stream cannot establish full-body proof. |
| `HistoryCheckpoints::get(session,sourceKind), replace_if_generation(expected,checkpoint)` | Bounded offsets, sparse index, fingerprints, observed native IDs, cursor and counts only. CAS rejects late readers after reset. Full native text, tool payloads and reasoning stay out of SQLite. |

For browser JSON under `GET /api/v1/runs/{runId}/sessions/{sessionKey}/history` mount `/page`, `/content`, `/navigation`, `/plan` with the shared envelope. `/stream` is scoped SSE and carries one of `changed | reset | availability | delta`. Serialize results explicitly. DTOs carry stable string IDs, lowerCamelCase fields, snake_case tags and nullable timestamps when native time is unknown. The service-wide durable event cursor and the native source cursor have independent types. [ENTRY](entrypoints.md) maps `ReadTranscript` to these app reads with tighter MCP page limits.

| Resource | Bound |
| --- | --- |
| Browser page | Default 30 entries/64 KiB, maximum 100/256 KiB serialized page data. Preview 512 characters. Stop at either bound. Smaller results retain a valid continuation. |
| Content, navigation | 64 KiB decoded text per chunk. Bounded overhead for JSON escaping at HTTP serialization. Navigation response ≤64 KiB. Up to 64 groups, 50 previews/page, 160 characters/preview. Project ≤32 tool identities/16 KiB metadata per entry. Expose overflow through the content reader. |
| Reader and viewer | Shared reader decoded/cache budget 16 MiB across sources, including in-progress projected buffers. Reserve memory before decoding or queuing. Bound socket frame ingress separately. Six retained browser pages, 8 MiB loaded content, two navigator preview pages. These are component budgets. Release QA measures process and tab footprints independently. |
| MCP and live | MCP page default 10 entries/16 KiB, maximum 25/32 KiB. Same content continuation with 64 KiB chunks. SSE delta ≤64 KiB decoded. Split serialized frames at scalar boundaries to fit a 70 KiB frame or emit a reset. One pending invalidation per blocked observer. |

## Reader implementation

1. Resolve an authenticated source address. Prefer Codex's registered exact path or `thread/read {threadId,includeTurns:false}` path. Verify `session_meta` thread ID. In the absence of an authoritative file address, use paged `thread/turns/list` and `thread/items/list`, preserving their native IDs, same-thread/parent relationship and cursor. A known missing or denied file remains diagnosable. For Claude, check the native registered path or look up the exact session ID in its selected `CLAUDE_CONFIG_DIR/projects` root. Verify embedded session ID. For children verify parent metadata's tool-use ID against that parent’s real spawn and child native agent ID. Recursively check ancestry. Resolve task files under the exact session's `tasks/<id>` and verify ID/fields. Only use verified regular files from allowed provider roots or explicitly configured, verified provider locations. Reject root escapes and swapped symlinks, compare the opened file’s identity with the proven source. A matching filename/cwd supplies no authority.
2. Process NDJSON from bounded read buffers. Scan newline and native byte positions incrementally even if one record spans hundreds of MiB. Decode an allowlist of display fields and stream requested scalar bodies. Preserve split UTF-8, JSON escapes and surrogate pairs across buffer boundaries. Use Struson's low-level pull reader with streamed string values and bounded nesting. Use a bounded input adapter/field-name and metadata budgets, including hostile oversized keys/scalars. An unsupported record can be skipped to its newline. Confirm memory on giant inputs before adopting its pinned release, since its maintainers flag pre-1.0 API and performance. `serde_json` remains appropriate for bounded DTOs. The large-scalar test exercises a different allocation path from streaming multiple objects. [Struson streaming and license](https://github.com/Marcono1234/struson) · [Serde JSON stream semantics](https://docs.rs/serde_json/latest/serde_json/struct.StreamDeserializer.html)
3. Capture a read high-water mark from the opened descriptor. Commit only through the last complete, identity-verified record boundary. Defer a partial tail to the next append. Treat malformed complete records as unsupported or skipped with a warning and a terminating continuation. Build a sparse index of visible ordinal, last confirmed prompt ordinal, native turn and tool-group boundaries. Bound to 4,096 points and 192 KiB serialized per active source index by increasing stride. Store only completed checkpoints, release file descriptors and reader slots at cancellation. Pool blocking reads on bounded workers and coalesce a concurrent index build for one generation. A paused scan preserves continuation and `complete=false`. Callers can still reach older data.
4. Identify source generation by provider/native identity, canonical locator, file identity (device/inode/birth where available), source prefix and committed-tail fingerprints. Stable append keeps generation. Truncation, file replacement, rewrite of observed boundaries, changed RPC lineage or loss of pinned source invalidates outstanding refs. Reopen and reverify after rotation, clear dependent caches/indexes, emit reset. Use keyed opaque cursor tokens carrying version, operation, target, source generation, direction/position, slot/block and MAC. Clamp token length to 8 KiB, use a stable private per-install key, reject altered/cross-target cursors. A valid stale token returns reset and the current generation, with no old bytes. Restore by exact entry ID only after proof. Otherwise offer a fresh tail and explanation.
5. Project only visible user prompts, assistant text, ordered call/result blocks, public plan/assignment, lifecycle, tool and request displays. Exclude private reasoning, hidden prompts, internal transport/compaction and secret answers. Use qualified native IDs for call/result pairing within source. Preserve mixed blocks, duplicate text, explicit completion/failure, incomplete group boundaries and unknown native names with bounded display. Use the tool display contract in the session spec. Confirm a terminal response as a distinct exact final item, preserving child and lead ownership. Derive user landmarks from confirmed provenance only.
6. Share an active file watcher using OS events through `notify`, watch the parent for replace/create, then stat and verify the file. WSL and filesystems with unreliable native events use a bounded polling fallback only for active sources. Coalesce change notifications and keep a fresh bounded tail. Live provider deltas carry exact turn/entry/block plus contiguous decoded **UTF-8 byte** offset. Translate the provider's native index/encoding at the adapter. Browser matches that generation/offset, drops identical already-applied fragments and reloads the canonical block on gaps/overlap. Tag provisional text until reconciled to durable output. File growth without live events still becomes visible. Share one native socket. The global event stream carries invalidations, never transcript bodies. [notify watcher guidance and license](https://github.com/notify-rs/notify)
7. Return `available | disconnected | missing | denied | unsupported` independently of execution status. Honor bounded retry hints for transient errors, back off with jitter up to 30 seconds and keep readable content. Heartbeat scoped SSE every 15 seconds. On a slow/disconnected socket, cancel reads, release its lease and collapse missed bodies into one reset. A reconnect first takes a fresh scoped snapshot at the last visible entry or live tail and reconciles one pending invalidation. Race-proof subscribe/snapshot ordering. Nothing in a read path dispatches, acknowledges a notification or authorizes an action.

## Verification

Run `cargo check --locked -p reviewq-providers -p reviewq-app -p reviewq-store -p reviewq-transport` and existing focused nextest packages. Through the candidate’s foreground service in a disposable SLICE profile, use synthetic Claude and Codex files with repeated text, linked child, mixed message/tool blocks, private events, split non-ASCII output and a scalar larger than 16 MiB. Read backward/forward, navigate to an old prompt, concatenate chunks and compare a streaming hash with the original visible scalar. Record max retained bytes and commit boundaries.

Append a partial line, finish it, rotate/truncate the file, replay a stale cursor and try a different run's ref. Expect exactly one newly completed row, no cross-source bytes, clear reset and successful reanchor or explicit unavailable state. Slow one reader while another tails and a report verifies an exact final. Disconnect/restart, observe the same source and zero hidden watchers after closing Agent. The reading viewport stays put through incoming activity and exact submission receipts do not repeat. Reuse a single integrated scenario where possible. Add a regression only for a concrete failure these checks miss. Retain the repository-wide 500-case ceiling.
